# Source for 중2 능률 김기택 Lesson 07 + Lesson 08 (j2-neung u07 / u08)

Printed book: `중2능률김기택 100발100중 7,8.pdf` (198 scanned pages, vFlat, OCR text layer).
Everything a run needs is in this folder. Nothing else is available: no Google Drive, no /tmp,
no other computer.

## What is in here

| Folder | Content |
| --- | --- |
| `text/P001.txt` … `text/P198.txt` | OCR text of each PDF page. First line gives the PDF page and the printed footer. Use it to find a page and to read most question stems. |
| `keys-img/P169.jpg` … `keys-img/P198.jpg` | The 답지 (정답 및 해설) pages as images. **The only trustworthy source for an answer key.** |
| `keys/L07.md`, `keys/L08.md` | Verified key sheet, read from the 답지 images by the task owner. Use it first. If a row says `unclear`, omit that item. |

**Never take an answer key from `text/`.** The OCR turns `①②③④⑤` into `(3)`, `0`, `@`, `5`.
An answer key comes from `keys/*.md` or from your own reading of `keys-img/`. If both are unclear,
put the item in `omitted[]` with its page and a reason. Never guess, never use the cycle `2,3,4,5,1`.

## Schema — copy `data/j1-neung/u07/exercises/*.json` exactly

Top level: `id`, `title`, `book` (`"j2-neung"`), `unit` (`"u07"` / `"u08"`), `sourcePages`
(string, for example `"pp.126"`), `questionCount`, `omitted`, `questions`, `sectionsVersion`,
`introKo`, `sections`.

`sections[]`: `id` (`s1`…), `title` (`"Section A · …"`), `directionKo`, `ruleKo`, `answerMode`,
`answerModeTag`, `instructionKo`, `itemCount`.

`questions[]`: `id`, `label`, `sourceId`, `section`, `sectionTitle`, `directionKo`, `ruleKo`,
`sectionInstructionKo`, `answerMode`, `answerModeTag`, `explainKo`, `type`, plus the fields for
its type. `explainKo` gives the answer, and it names the 답지 page.

| `type` | Extra fields | Student action |
| --- | --- | --- |
| `mc` | `select` (`one`/`multi`), `promptEn`, `choices[]`, `correctIndexes[]` (1-based) | tap a choice |
| `fill` | `promptEn`, `accept[]`, `phraseBlank` (bool; true when the answer is 2+ words) | type the one blank |
| `sentence` | `promptEn`, `accept[]` | type the whole sentence |
| `order` | `promptEn`, `orderChunks[{id,text}]`, `orderIds[]` | tap words in order |
| `match` | `promptEn`, `pairs[{id,en,ko,sourceId,explainKo}]` | tap English then Korean |
| `bank` | `promptEn`, `choices[]`, `correctIndexes[]` (one), `focusBlank`, `promptKo` | tap a word-bank word for one blank |
| `ox` | `promptEn`, `oxMark` (`O`/`X`), `rewriteAccept[]` | tap ○/× and type the fix |
| `parts` | `promptEn`, `parts[{kind,label,choices,correctIndexes,indexBase,accept,placeholder}]` | several parts on one card |

`seconds`: 45 for a tap item, 70 for one written blank, 100 for a full sentence, 18 per matched
pair, 75 for an order card.

## Rules

1. Student-facing text is English. Korean only in `directionKo`, `ruleKo`, `explainKo`, `introKo`,
   `sectionTitle`, `answerModeTag`, and a Korean line the book prints as part of a stem.
2. Every card must be answerable on its own: the stem carries the passage, the underlined or
   circled marker, and the blank number. A card that says `밑줄 친 ⓐ` must show `ⓐ` in `promptEn`
   as `<u>…</u>`, the same way `data/j1-neung/u07` does. Use `<u>` for an underline and keep `ⓐ`.
3. Item numbers follow the book, not the array index. `label` is the printed number.
4. Write `omitted[]` entries as `{"page": "p.140", "item": "07", "reason": "…"}`.
5. Write only your own exercise files plus one `catalog-fragment-<group>.json` at
   `data/j2-neung/u07/` or `u08/`. **Do not edit `catalog.json`, `data/books.json`, any other
   exercise file, `data/j1-*`, `data/j2-donga`, `data/_demo`, `assets/`, or the site HTML.**
6. Open a pull request. Do not merge it.
7. Run `python3 scripts/check-j2n78.py` before you open the pull request. It must print `OK`.
